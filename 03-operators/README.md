# 03 Operators

## ภาษาไทย
โน้ต: หารจำนวนเต็มตัดเศษ, ไม่มี `++`/`--` (ใช้ `+= 1`), เช็คเท่ากันใช้ `==` ตรงๆ ได้เลย (ไม่มี `===` แบบ JS)

รัน: `rustc --edition 2021 main.rs -o main && ./main`

## English
Note: integer division truncates, no `++`/`--` (use `+= 1`), `==` compares by value directly (no JS-style `===` needed)

Run: `rustc --edition 2021 main.rs -o main && ./main`
