# 09 Iterators

## ภาษาไทย
โน้ต: `map` แปลง, `filter` กรอง, `find` เอาตัวแรก, `fold`/`sum` รวมยอด — iterator ขี้เกียจ ต้อง `.collect()` มาจบถึงจะทำงาน

รัน: `rustc --edition 2021 main.rs -o main && ./main`

## English
Note: `map` transforms, `filter` filters, `find` gets first match, `fold`/`sum` aggregates — iterators are lazy, nothing runs until `.collect()`

Run: `rustc --edition 2021 main.rs -o main && ./main`
