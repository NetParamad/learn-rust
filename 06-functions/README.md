# 06 Functions

## ภาษาไทย
โน้ต: บรรทัดสุดท้ายไม่มี `;` = return ค่านั้น, `closure` แทน arrow fn, ไม่มี default param (ใช้ `Option` + `unwrap_or`)

รัน: `rustc --edition 2021 main.rs -o main && ./main`

## English
Note: last line without `;` returns that value, `closure` replaces arrow fn, no default params (use `Option` + `unwrap_or`)

Run: `rustc --edition 2021 main.rs -o main && ./main`
