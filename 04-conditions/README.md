# 04 Conditions

## ภาษาไทย
โน้ต: `if` เป็น expression คืนค่าได้ (แทน ternary), `match` แทน `switch` แต่บังคับครบทุกเคส (`_` คือ default)

รัน: `rustc --edition 2021 main.rs -o main && ./main`

## English
Note: `if` is an expression that returns a value (replaces ternary), `match` replaces `switch` but must be exhaustive (`_` is the default)

Run: `rustc --edition 2021 main.rs -o main && ./main`
