# 05 Loops

## ภาษาไทย
โน้ต: `loop` วนไม่รู้จบ (คืนค่าได้ด้วย `break ค่า`), `0..5` ไม่รวม 5 / `0..=5` รวม 5, `enumerate()` ได้ index ฟรี

รัน: `rustc --edition 2021 main.rs -o main && ./main`

## English
Note: `loop` runs forever (can return a value via `break value`), `0..5` excludes 5 / `0..=5` includes 5, `enumerate()` gives index for free

Run: `rustc --edition 2021 main.rs -o main && ./main`
